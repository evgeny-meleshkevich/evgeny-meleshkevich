## About me

I build applications for automating work, collecting and analysing data, and processing documents and images. My projects connect APIs, local tools and AI models — from browser-based analytics to a macOS assistant and image processing on cloud GPUs.

I focus on the complete workflow: collecting inputs, processing them and presenting results people can review and use.

## Technical stack & capabilities

**AI Assistants & Agents**<br>
Voice and multimodal interfaces, tool calling, specialist task queues and local memory.

**Data Collection & Analytics**<br>
Browser automation, recurring monitoring, historical snapshots and interactive analysis.

**Cloud GPU Processing**<br>
ONNX inference on NVIDIA GPUs, tiled image processing and batch workflows.

**Workflow Automation**<br>
API-backed applications, document generation, role-based access and native macOS integrations.
