### 👨‍💻 About Me

I design and build **desktop AI applications**, **continuous web scrapers**, and **data automation pipelines**. My projects solve concrete operational tasks: from automated photo inspection of salvage auction lots to tiled neural upscaling on cloud GPUs and regulatory document generators.

- 🎙️ **Desktop AI & Local Agents:** Multimodal desktop applications with speech input, local context memory, and native macOS execution ([JARVIS macOS](https://github.com/evgeny-meleshkevich/jarvis-macos)).
- 🔍 **Vision & Multimodal Filters:** Automated lot screening with Gemini Vision, damage grading, corrosion risk analysis, and adaptive user correction memory ([Auction Scout](https://github.com/evgeny-meleshkevich/auction-scout)).
- 📊 **Market Intelligence & Scraping:** Robust crawlers with anti-ban headers, price change timelines, duplicate lot detection, and local SQLite analytics ([MotorScope](https://github.com/evgeny-meleshkevich/motorscope), [SkillScope](https://github.com/evgeny-meleshkevich/skillscope)).
- ⚡ **Cloud GPU Neural Inference:** Serverless ONNX pipelines on NVIDIA L4 with linear-weighted tile blending to process ultra-high resolution images without seams or VRAM overflow ([Batch GPU Upscaler](https://github.com/evgeny-meleshkevich/batch-gpu-upscaler)).
- 📄 **Regulated Document Workflows:** Reliable data transformation from complex employee spreadsheets into print-ready, legally compliant PDF referrals ([Medical Referral Demo](https://github.com/evgeny-meleshkevich/module-mo-po-demo)).
